使用帮助

快速开始（6 步）

  1. 启动：双击 start.bat，浏览器会自动打开本页面。
  2. 配置：选择 LLM 模式（本地 Ollama 零成本 / OpenAI 兼容接口），点「测试 LLM 连接」看到绿灯。
  3. 视频：默认「模拟模式（Mock）」，无需任何 Key 即可出片；如需真实出片再选「RunningHub（工作流 i2v）」并填 API Key（复用「视频 API Key」）。
  4. 输入：粘贴一段粗糙对话（或用「载入示例对话」），选择风格、镜头数、时长、分辨率。
  5. 生成：点「开始生成」，进度区会实时显示五个阶段：剧情补全 → 分镜脚本 → 分镜视频 → 视频拼接 → 质量评估。
  6. 确认分镜（默认开启）：勾选「生成前确认分镜」后，脚本生成完毕会停在「③.5 分镜确认区」，可修改剧情/分镜后再点「确认并生成视频」；不想确认可在输入区取消勾选。
  7. 逐段确认（串行首帧链）：确认分镜后进入「③.6 逐段确认区」，上传一张「初始图」后，程序逐段生成、逐段等待你「接受并继续」，全部接受后自动拼接成片。
  8. 剪辑与导出：在「④ 视频剪辑区」的时间轴上拖拽排序 / 双臂裁剪 / 一刀两段，实时预览后点「导出成片」，生成新文件（不覆盖原始成片）。

剧情补全 与 剧情编辑

  • 系统会先把粗糙对话补全为完整故事情节（story.json），再据此拆解分镜提示词。
  • 点进度区「查看剧情」打开剧情弹窗：标题 / 题材 / 梗概 / 场景设定 / 完整情节均可直接编辑（角色与情节节点为只读参考）。
  • 改完点 「保存并重新生成分镜」：会新建一个任务，用你改好的剧情直接生成分镜，跳过剧情补全阶段（省一次 LLM 调用）；当前任务与产物不受影响。
  • 镜头数、单镜头时长、风格、分辨率沿用「② 输入区」的设置——想改这些请先在输入区调好再点该按钮。

分镜确认区（③.5）

  • 勾选「生成前确认分镜」后，脚本生成完毕会先挂起，出现「③.5 分镜确认区」，此时尚未生成任何视频。
  • 左侧可修改完整剧情（标题 / 题材 / 梗概 / 设定 / synopsis），右侧可逐条修改每个镜头的分镜提示词 / 动作 / 运镜 / 对白 / 时长。
  • 确认并生成视频：若改了剧情 → 重跑脚本；只改分镜 → 直接采用；随后在同一任务内继续生成视频与报告。
  • 跳过确认：不做修改，按当前分镜直接生成。
  • 时长须为 2–10 秒、分镜提示词不能为空，否则会提示并保持挂起、不会开始生成。

专业剪辑区（④ 时间轴）

  • 播放头与刻度尺：顶部为秒刻度尺；播放头随预览播放移动。单击刻度尺或轨道可定位播放头。
  • 排序：直接拖动片段块到目标位置即可重排。
  • 裁剪：拖动片段左右两侧的手柄调整 in / out（起点不得越过终点，越界自动回退）。
  • 启用/禁用：点击片段左上角的 ✓ / ⊘ 切换；禁用的片段置灰，不参与预览与导出。
  • 一刀两段（分割）：选中片段并把播放头落到该片段内部，点「✂ 在播放头处分割」，即拆为两段，可各自排序 / 裁剪 / 启用。
  • 预览：点「▶ 播放剪辑」按当前时间轴顺序播放，播放头同步走动。
  • 导出：点「导出成片」生成 exports/export_<时间戳>.mp4 与配对方案 exports/edit_plan_<时间戳>.json（含每个片段的 clip_id），绝不覆盖 final_video.mp4。
  • 刷新恢复：剪辑方案会自动保存到服务端（edit_plan_draft.json）。误关页面或刷新后会自动恢复；旧草稿（无 clip_id）按「每镜头一段」原样还原。

常见问题

  • FFmpeg 缺失：顶部会出现红色提示；请安装 FFmpeg 并加入 PATH（下载：gyan.dev/ffmpeg/builds）。
  • Ollama 未启动：提示「无法连接 localhost:11434」，请先执行 ollama serve，或在配置区手动填写 Base URL。
  • JSON 解析失败：部分小模型输出不稳定，系统会自动重试 2 次；仍失败请更换更大的模型。
  • 某段生成失败：不会中断整个流程，可在「③.6 逐段确认区」对该段点「重生成本段」（自动换随机种子重试）。
  • 端口被占用：服务会自动使用 8001、8002……，顶部会显示实际地址。

产物位置

每次任务生成独立目录 outputs/<时间戳>/，内含 story.json（完整剧情）、script.json、shots/、frames/、final_video.mp4、evaluation_report.json；剪辑导出的成片与方案位于 exports/ 子目录（配对命名，不覆盖原始成片）。
