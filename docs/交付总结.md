## 一、TL;DR

**一句话**：把「一段随便写的对话」变成「有分镜、有视频、有评估报告的小短剧」，全程网页点鼠标完成，双击 `start.bat` 即用。

一条完整流水线由三个智能体协作完成：

```
粗糙对话 →【ScriptAgent】→ 分镜脚本 JSON →【DirectorAgent】→ 多镜头视频 →【FFmpeg 拼接】→ 成片 →【CriticAgent】→ 评估报告
```

对标腾讯开源 `Tencent/digitalhuman` 的 **ScriptAgent** 多智能体框架。

## 六、已知限制与遗留项

| 编号 | 级别 | 说明 |
| --- | --- | --- |
| L1 | 信息 | 视频适配器现为 **Mock（P0）+ RunningHub 模型 API（真实，文生视频）** 两个；RunningHub 模型 API **不接受首帧参考图**，故逐镜头视觉连续性由参考图保证的能力在真实出片时**不生效**（忽略并记 warn）。如需视觉连续性请改用 RunningHub 的 AI 应用/工作流 API。 |
| L2 | 信息 | 本机 Ollama CPU 推理较慢（单次 JSON 生成约 100–160s）。建议使用较小模型，或换用远程 OpenAI 兼容接口。Mock 视频本身极快（单镜头 <1s）。 |
| L3 | 信息 | 首次使用需在配置区点「刷新」选择本机已装模型（默认值 `qwen2.5:14b` 本机可能未安装）。 |
| L4 | 信息 | 未做：脚本 JSON 在线编辑后重生成（P1-4）、历史任务列表（P2-3）、批量处理（P2-1）、SSE 推送（默认轮询）、1080p/高并发压测。均属 P1/P2 可选范围。 |
| L5 | 家政 | `E:\ai\storyforge\logs\` 下有 9 个 `_*.txt` 临时草稿文件（工程师排查遗留，纯文本、无害、不影响运行）。受删除保护策略限制未能自动清理，可手动删除。 |

## 八、用户下一步建议

1. **先零成本体验**：双击 `start.bat`，LLM 用本机 Ollama，视频用 Mock，跑一遍完整流程确认可用。
2. **阅读 `docs\使用说明.md`**：覆盖安装 / 启动 / 配置 / 跑通 / 常见问题五章，含排查指引。
3. **接入真实 LLM**：在配置区切到「OpenAI 兼容接口」，填 `base_url` + `api_key` + `model`（如 DeepSeek `https://api.deepseek.com/v1`），点「测试连接」确认绿灯。
4. **接入真实视频 API**：在配置区选「RunningHub（模型 API）」，填 `video_api_key`（需「企业级-共享」Key）；`video_base_url` / `video_model` 留空即用国内默认端点（`https://www.runninghub.cn` 与默认模型端点路径）。详见 `README.md` 与 `docs/使用说明.md` §3.3。
5. **保留验收证据**：`outputs/20260915_174614/`（真实 Ollama 全流程）、`outputs/20260915_180602/` 等目录可作为验收留档。
